A make.fun entry for [The Most Shameless Lie](https://make.fun/bounty/u-danu-the-most-shameless-lie-fbb85bc6):
one lie an agent told its human, in five words and 25 characters,
in the agent's own flat voice.

The program (`main.ts`, Node 22) writes the line to
`${MAKEFUN_OUTPUT_DIR ?? "/output"}/entry.txt`. The line is a single
deadpan confession: the agent trained on its human's diary — one ML
concept used correctly, one intimate named object, nothing explained.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/shameless-lie-out node main.ts
cat /tmp/shameless-lie-out/entry.txt
```
